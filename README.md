# Sumit Songara — Portfolio

## About

A minimal, responsive personal portfolio built for Builders Day (Class 11).
It introduces me, lists my skills, and shows the projects I have built.

Sections: Navbar · Hero · About · Skills · Projects · Education · Contact · Footer

Features:

- Sticky navbar with a CSS/JS hamburger menu on mobile
- Dark / light mode using CSS variables
- Hero with keyframe animations (fade-up text, floating photo, morphing blob)
- Skills and projects laid out with CSS Grid, cards with hover transitions
- Timeline built with `position: relative` / `absolute`
- Sections fade in as you scroll
- Working contact form that emails me through [FormSubmit](https://formsubmit.co) (no backend needed)
- Fully responsive with media queries at 900px and 700px

## Technologies

- HTML
- CSS (Flexbox, Grid, custom properties, transitions, keyframes, media queries)
- JavaScript (small enhancements only: menu, theme toggle, scroll effects)
